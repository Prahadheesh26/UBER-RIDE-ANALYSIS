# 🚗 Uber Data Analysis Project

## 📊 Project Overview

This project performs **exploratory data analysis (EDA)** on an Uber trip dataset using **Python**.
The goal is to understand ride patterns, user behavior, and time-based trends such as **peak hours**, **ride purposes**, and **daily travel distances**.

Through visualization and analysis, this project uncovers meaningful insights from the dataset that can help optimize ride operations and identify user demand trends.

---

## 📁 Dataset Information

**File Name:** `uberdatasett.csv`

The dataset contains trip details including start and end timestamps, travel locations, distance, and purpose of travel.

| Column Name | Description                         |
| ----------- | ----------------------------------- |
| START_DATE  | Date and time when the ride started |
| END_DATE    | Date and time when the ride ended   |
| CATEGORY    | Type of trip (Business/Personal)    |
| START       | Starting location                   |
| STOP        | Destination location                |
| MILES       | Distance traveled (in miles)        |
| PURPOSE     | Purpose of the trip                 |

---

## 🧠 Objectives

1. Clean and preprocess the dataset.
2. Extract and create new time-based features like **Day**, **Month**, and **Hour**.
3. Analyze ride frequency by day of the week.
4. Identify **peak hours** for rides.
5. Visualize **daily travel distances** and trends.
6. Explore the **purpose of rides** distribution.
7. Identify long-term ride trends using a **7-day moving average**.
